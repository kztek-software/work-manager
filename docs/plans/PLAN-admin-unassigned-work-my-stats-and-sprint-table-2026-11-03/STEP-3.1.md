# STEP-3.1: Kiểm Tra Toàn Diện TypeScript, Chạy Thực Tế & Xuất DOCX/PDF

## Mục tiêu
- Chạy `npx tsc --noEmit` đảm bảo không có lỗi type nào.
- Kiểm tra tính năng phân công việc, xem thống kê theo nhân sự, và hiển thị bảng Sprint Detail.
- Chạy `python scripts/md_to_docx_kztek.py` xuất file DOCX và PDF cho plan.
