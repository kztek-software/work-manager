# STEP-1.1: Tối ưu Bảng Sprint Detail Dialog - Đẩy Cột Trạng Thái Sang Phải & Mở Rộng Cột Tiêu Đề

## Mục tiêu
- Sửa layout container bảng: thêm `w-full` kết hợp `min-w-[850px]` để bảng trải rộng 100% không gian dialog `max-w-5xl`.
- Cấu hình lại `grid-cols-[85px_1fr_95px_50px_75px_110px_110px_32px]` để cột Tiêu đề dùng `1fr` nhận trọn phần chiều ngang còn lại.
- Cột Trạng thái và nút gỡ task sát lề phải, căn chỉnh dropdown trạng thái gọn gàng và thẩm mỹ.
